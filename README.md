# bank_management_system
A simple bank management system built with Python.

## Project Description
A Python Bank Management System using OOP, multiple accounts, login, money transfers, transaction history, admin panel, and JSON storage.

## Features

* Create new bank accounts
* Automatic account number generation
* Login system with password
* Deposit money
* Withdraw money
* Check account balance
* Transfer money between accounts
* View transaction history
* Change account holder name
* Admin panel
* Search accounts
* Delete accounts
* Show all accounts
* Show total bank balance
* Save data using JSON

## Technologies Used

* Python
* Object-Oriented Programming
* JSON file storage

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Run the Python file:

```bash
python bank_management_system.py
```
